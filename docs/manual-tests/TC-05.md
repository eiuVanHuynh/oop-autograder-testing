# TC-05 - Thiết lập tài khoản Google lần đầu

- Trạng thái: [ ] Pass  [x] Fail  [ ] Blocked - lý do: ........

## Các bước
1. Mở /login, bấm "Sign in with Google", chọn tài khoản mới
2. Hệ thống yêu cầu đặt IRN và mật khẩu (trang /setup-account)
3. Nhập IRN theo quy tắc (2099 + 6 số), mật khẩu từ .env (>= 8 ký tự), nhập thêm các ô khác nếu có (Name, ngày sinh tùy chọn)
4. Bấm "Complete Setup"

## Kết quả mong đợi
Tài khoản Google được liên kết với IRN, tạo hồ sơ, rồi chuyển vào dashboard theo vai trò (xem TC-03).
